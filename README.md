# 🎓 StudyPlan — Студенческий Дашборд (Student Dashboard)

Современный, интерактивный и удобный веб-дашборд для студентов, созданный для организации учебного процесса, управления расписанием, задачами и экзаменами.

---

## ✨ Основные функции

- 📋 **Ближайшие задания (Tasks):** Добавление, редактирование, фильтрация (Все, Активные, Завершенные) и удаление задач с указанием приоритетов (Высокий, Средний, Низкий).
- 📅 **Расписание на неделю (Timetable):** Удобное переключение по дням недели (Пн–Сб) с возможностью добавлять, редактировать и удалять пары/занятия.
- 🗓️ **Автоматический Календарь:** Динамический календарь с навигацией по месяцам и авто-определением текущего дня.
- ⏳ **Ближайшие экзамены:** Контроль предстоящих экзаменов с функцией добавления, редактирования и удаления.
- 📊 **Прогресс по предметам:** Интерактивные полосы прогресса успеваемости с возможностью управления списком предметов.
- 🔔 **Уведомления:** Всплывающее окно уведомлений о дедлайнах и экзаменах.
- 👤 **Настройки профиля:** Модальное окно для кастомизации имени студента.
- 💾 **LocalStorage:** Все данные (задачи, расписание, экзамены, профиль) сохраняются прямо в браузере.

---

## 🛠️ Используемые технологии

- **HTML5** — структурирование страницы.
- **CSS3 (Flexbox, Grid, CSS Variables)** — стилизация, современный и адаптивный дизайн.
- **JavaScript (ES6+)** — интерактивность, логика управления состоянием и работа с `localStorage`.
- **Google Fonts (Inter)** — типографика.

---

## 🚀 Как запустить проект

1. Скачайте или клонируйте репозиторий.
2. Убедитесь, что файлы **`index.html`** находятся в одной папке.
3. Откройте файл **`index.html`** в любом современном веб-браузере (Chrome, Firefox, Edge, Safari).
